## Installation 🛠️

To get a local copy up and running, follow these simple steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Unknown1648/Developers-Portfolio.git
    cd Developers-Portfolio
    ```

2.  **Install dependencies:**
    This project uses npm and Vite. Install the necessary packages:
    ```bash
    npm install
    ```

3.  **Run the development server:**
    Start the Vite development server to view the portfolio locally:
    ```bash
    npm run dev
    ```

This will start the development server, and you can access the portfolio at `http://localhost:5173` (or the port indicated in your console).

## Usage 🚀

This project serves as a personal developer portfolio, showcasing skills, projects, and qualifications.

**Key Use Cases:**

-   **Showcasing Projects:** The `Projects` page displays a curated list of personal and professional projects, including descriptions, technologies used, and links to their respective GitHub repositories. This is crucial for demonstrating practical application of skills.
-   **Highlighting Skills & Experience:** The `About Me` section elaborates on the developer's approach, philosophy, and expertise. The `Resume` page offers a downloadable CV for a more formal overview.
-   **Demonstrating Technical Proficiency:** The use of modern technologies like React, Vite, and Tailwind CSS, along with interactive UI elements and animations, demonstrates up-to-date technical skills.
-   **Facilitating Contact:** The `Contact` page provides multiple ways to get in touch (form, email, phone), making it easy for potential employers or collaborators to reach out.
-   **Displaying Certifications:** The `Certifications` page lists relevant training and certifications, validating the developer's knowledge in specific areas.

**How to Interact:**

-   **Navigation:** Use the top navigation bar to move between sections (Home, About, Projects, Resume, Contact). The current page is highlighted.
-   **Interactivity:** Experience smooth animations and mouse-following effects. Hover over project cards and certification cards to reveal more details and interactive elements.
-   **Theme Switching:** Click the theme toggle button in the navigation bar to switch between light and dark modes.
-   **Contacting:** Fill out the form on the `Contact` page or use the provided email and phone number.
